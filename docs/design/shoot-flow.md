# 拍照引导页与拍照页（含拍后确认、备选照片）

- 日期：2026-11-20
- 状态：已定稿（用户：“全部按照你的建议来”）。实现：T025（引导页、拍照页、拍后确认）、T026（保存与备选）
- 上位文档：`docs/design/miniapp-ux-v2.md`（视觉变量、文案规则）

## 1. 用户在这两个页面在想什么
- 引导页：我这样拍能行吗？拍出来会不会丑？会不会被退回？
- 拍照页：脸放哪、离多远？姿势光线对不对？自拍按不了快门怎么办？拍坏了能马上重来吗？

优先级：**拍得合格 > 拍得好看 > 拍得省事**。被退回比不好看更让人沮丧。

## 2. 引导页（原 ShootGuide 面板升级为独立页面 `pages/shoot-guide`）
从上到下：
1. 标题“这样拍，一次过”。
2. **示范图**：用插画表现“正确”与三种常见错误（侧脸、头太小、背光），不用真人照片。插画用 CSS/SVG 画剪影即可。
3. 四条要点（是步骤性内容，可编号）：
   1. 手机举到眼睛高度，离远一点，把肩膀也拍进来（2026-11-20 加：真实自拍测试中，近距离、从下往上拍导致肩膀缺失、裁剪后底部出现空白）
   2. 正对镜头，露出眉毛和耳朵，表情自然
   3. 面朝光线，脸上不要有明显阴影
   4. 不用找白墙，穿深色上衣会更好看
4. **常见问题，默认收起**：能戴眼镜吗（建议摘掉，避免反光；部分证件不允许）、头发怎么处理（别遮眉毛和耳朵）、可以化妆吗（淡妆可以）。
5. 底部：主按钮“开始拍照”，次按钮“从相册选”；“下次不再提示”勾选（勾选后从首页直接进拍照页）。
- 不出现：价格、证件类型选择。

## 3. 拍照页（新页面 `pages/camera`，用小程序 `Camera` 组件）
- 全屏取景，**默认前置摄像头**。
- **人像轮廓框**：半透明头肩轮廓居中，标出“头顶线”和“下巴线”两条参考线。尺寸按自拍习惯定（2026-11-20 真机反馈“框太小、离人太远”后调整）：外框铺满屏宽，头部轮廓约占屏宽 54%（矮屏按高度缩小），肩部轮廓从下巴延伸到底部，伸直手臂自拍就能放进框里，文案“手机举到眼睛高度，把脸和肩膀都放进框里”。
- 顶部：切换前后摄像头、倒计时开关（关 / 3 秒，默认 3 秒）、补光开关。
  - 补光：前置摄像头没有闪光灯，补光为“屏幕调到最亮 + 取景框外圈白色”；后置摄像头用闪光灯。离开页面恢复原亮度。
- 底部：大快门按钮；左侧“相册”入口。
- 倒计时期间屏幕中央显示 3、2、1，可点“取消”。
- 拍完进入**拍后确认**：大图显示刚拍的照片，按钮“用这张”（主）/“重拍”。
- **权限**：首次进入请求相机权限；被拒时显示说明和“去设置打开”，并保留“从相册选”。
- 第一版不做实时提示（小程序实时帧分析成本高），改为**拍后即检测**（见 4）。

## 4. 拍后即检测
点“用这张”后上传，后端返回快速检测结果（T024 提供，`PhotoOut.quality`）：
- 不合格（如没检测到人脸、多张人脸）：直接提示原因和怎么改，按钮“重拍”为主、“仍然使用”为次。
- 有建议（如脸偏小、偏暗、没正对镜头）：在制作页顶部一条提示，不打断。
- 合格：不提示，直接进制作页第 1 步。

## 5. 保存与备选（T026）
- 拍完进入制作页第 1 步修好看。此时照片是**临时的**，不进“我的照片”；24 小时内没保存自动删除。
- 制作页第 1 步加按钮“保存到我的照片”（免费）。
- **免费备选最多 3 张**（不含已付费照片），保存 30 天，到期前提醒一次。满 3 张时再保存，提示先删除一张。
- 选证件之前，若有 2 张以上备选，提供左右滑动对比，挑一张往下走。
- 付费相关规则（付费后另外几张怎么算）待与用户单独讨论，T026 不改套餐规则。
