# 需求与业务规则（精简版）

完整版见 Claude Doc「需求定义 v0.3」。这里只保留写代码必须知道的规则。

## 产品是什么

微信生态里的证件照工具：拍照或上传 → 自动做成各种规格的证件照 → 可在线办理官方“照片回执”（如身份证、社保卡、驾驶证用的数码回执）→ 照片云端保管，期内随时下载、换规格。

- 无广告，靠付费套餐赚钱。
- 私域运营：引导加企业微信、关注公众号，靠手机号和企业微信好友做后续营销（不拿照片做营销）。
- 以后还会做：冲印、3D 手办、更多端（网页、支付宝、抖音小程序）。
- 一个人开发，AI 协助；后端 Python。

## 套餐（必须可配置，不能写死在代码里）

| 套餐 | 价格 | 内容 |
|---|---|---|
| 单次精修 + 回执 | 19.9 元 | 精修一张照片 + 一次回执 |
| 单张照片年度保管 | 39.9 元 | 单张照片保管一年，期内无限下载、换规格，可查看回执；被驳回可免费重提 3 次 |
| 加办一种回执 | +10 元 | 同一张照片再办另一种回执 |
| 年度不限次 | 99 元 | 一年内不限次换照片，最多 10 次回执提交；一卡一人 |

套餐由 `plans` + `plan_benefits` 配置，权益类型：保管天数、照片范围、回执次数、重提次数、可否换规格、一卡一人、附加到主权益。

## 关键规则

- **到期**：保管期过后不能下载、不能换规格，页面显示“续费”；续费后恢复。
- **驳回**：回执被驳回可以换一张新照片重提；驳回不扣回执次数（服务商只在成功时收费）。
- **一卡一人**：99 元套餐第一次办回执时绑定身份证号（存哈希），之后只能给同一人办。
- **注销账号**：立即删除该用户全部照片文件。
- **照片存储**：放对象存储，按固定规则命名，方便检索：
  `{env}/u{user_id}/{p<photo_id>|a<app_id>}/{kind}[_{spec_code}_{bg}_b{beauty}]_f{file_id}.{ext}`
- **回执覆盖范围**：只有官方有采集系统的地区和证件能办；能办的规格由 `provider_specs` + `route_rules` 决定。
- **服务商**：鹧应（zjzapi.com）、黔微云（qwyun.top）—— 两家是同一个上游，`upstream_group` 相同，不能互为备份；办证直通车需要以照相馆身份注册（营业执照要有“摄影扩印服务”）。
- **通知**：回执出结果（成功/驳回）要通知用户：小程序订阅消息 → 公众号模板消息 → 企业微信 → 短信，逐级升级。

## 安全与隐私

- 手机号、身份证号加密存储，另存带密钥的哈希用于查找；日志不打印。
- AppSecret、session_key 不下发前端；令牌不放 URL。
- 演示数据只用假手机号、假身份证号。

## 分期

1. 一期：小程序拍照/上传、做证件照、套餐购买、回执办理与通知、照片保管与下载、运营后台。
2. 二期：公众号网页、企业微信私域自动化、冲印。
3. 三期：支付宝/抖音小程序、3D 手办。
