# ADR 0002 登录用服务端会话令牌，不用 JWT

- 状态：已采纳（2026-11-19）

## 决定
登录后发 32 字节随机令牌，库里只存 SHA-256（auth_sessions / admin_sessions）。C 端走 Bearer 头，滑动 7 天、绝对 30 天；后台走 httpOnly Cookie + CSRF 头，滑动 2 小时、绝对 12 小时。

## 理由
JWT 发出去收不回，退出、封号、注销后仍有效；本项目每个请求本来就要查库，多查一次会话成本很小，换来立即吊销。小程序 401 后可静默 wx.login 重登，不需要刷新令牌。

## 代价
每个请求多一次查询；量大时把会话放 Redis，接口不变。
