# T022 小程序“先选城市，再选规格”

- 状态：已完成（PR #14）
- 依赖：T020（界面 v2）、T021（规格聚合与地区接口）已合入
- 背景：ADR 0006；用户要求“用户先选城市，然后再去选自己想要的规格”，并展示所有服务商能办的全部规格。

## 只允许改的文件
`miniapp/src/`；后端只允许改 `backend/app/modules/specs/`、`backend/tests/specs/`，以及用 `scripts/export_openapi.py` 重新生成 `docs/api/openapi.json`。

## 交互设计（Opus 定稿）
1. **城市是规格选择的第一步，但可以跳过**：只办普通一寸照的人不该被城市拦住。
   - 首次点“开始拍”或首页规格区时，先弹“城市面板”；选过后记在本地（`Taro.setStorageSync('city', {code, name})`），之后直接进选规格面板。
   - 城市面板标题“你在哪里办证？”，说明一句“不同城市能办的回执不一样”。数据来自 `GET /spec-regions`：按省分组，省下列城市（直辖市/只有省级规格的省直接可选省）。每项右侧显示可办规格数。
   - 底部次按钮“我的城市不在这里”：记为“全国”（code 为空），只看全国通用规格。
   - 不请求定位权限（避免一进来就弹授权）。
2. **当前城市随处可见、随时可改**：首页标题区上方一个城市胶囊（“广州市”，未选为“选择城市”），选规格面板标题右侧同样一个，点击打开城市面板。改城市后首页和面板的规格列表重新加载。
3. **规格列表按城市过滤**：`listSpecs` 传 `region_code`（城市码，或只有省级时传省码）。选规格面板和首页“办证要回执？”一节把结果分两组：“{城市}可办”（`region_code` 非空的）在前，“全国通用”在后；组内顺序按接口返回。
4. **办理回执表单**：表单里有 `city` 字段时，用当前城市名预填（用户可改）。
5. **去掉首页的 N 次详情请求**：后端 `SpecOut` 增加 `supports_receipt: bool`（与 `SpecDetail` 同口径：有启用的服务商映射 + 启用的路由规则 + 服务商启用），列表接口批量计算（一次查询，不要逐条）；小程序 `SpecTile` 直接用列表字段，删掉为此做的详情请求。
