# 0037 后台照片与用户来源应用（T029）

- 日期：2026-11-20
- 状态：已完成，待 PostgreSQL 联调

## 需求

> 这个每个用户上传的图片能不能在运营后台看到啊？而且我现在测试，按理来说，应该会新增一个用户才对？我们的用户表没有区分是哪个小程序，后续如果换小程序也不知道是哪个小程序带来的客户。这些细节给补充下

## 拆解

1. 登记客户端应用，在首次注册时记录来源，为历史用户提供独立回填脚本。
2. 后台展示并筛选来源应用，允许所有者编辑应用名称和状态。
3. 为有权限的运营人员提供照片网格和预览，查看详情时留存审计记录。
4. 更新接口契约，验证权限、回填、分页和签名链接。

## 方案与决定

- 登录按平台和 AppID 登记应用，新用户保存首次注册应用。历史回填只填写空值，按身份创建时间、身份 ID 升序确定来源，旧网页身份 `h5` 对应应用平台 `web`。
- 应用停用用于运营标记，已有和新增用户仍按登录模块原有规则处理。停用后应用仍可用于查询历史归因。
- 照片摘要和详情要求 `photo:read`，仅所有者和运营角色拥有权限。每次成功读取详情写入 `photo.view`，审计只记录操作人和照片 ID。图片链接有效期 10 分钟，已经清理的照片保留摘要，文件地址为空。

## 改动

- 新增迁移 `5dc2f47a9b81`，创建 `client_apps` 并给 `users` 增加可空的 `source_app_id` 外键和索引。新增历史数据回填脚本。
- 后台增加四个接口，分别用于查询和编辑应用、查询照片列表与详情。用户查询增加来源筛选、来源应用和首次渠道，用户详情最多展示最近 12 张照片。
- 管理端增加照片网格、Ant Design Image 预览、应用编辑。预览打开期间会续取临时地址。更新共享权限、模型导出、模块契约和 OpenAPI 快照。
