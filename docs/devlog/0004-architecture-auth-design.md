# 0004 架构规范、登录与权限设计

- 日期：2026-11-19
- 状态：已完成

## 需求
“想看登录和令牌怎么设计？现在这一套有架构和项目规范吗？如果后期长期迭代维护，如何保证可扩展性和可维护性？”

## 方案与决定
- 模块化单体：一个服务一个库，按业务模块划边界；模块内 router → service → repo → models；外部服务走 integrations 适配器。见 ADR 0001。
- 登录用服务端会话令牌而不是 JWT（可立即吊销）。见 ADR 0002。
- 权限三道关：接口入口验令牌、业务层验规则、数据访问层只查本人数据（别人的返回 404）；后台用权限点 + 角色映射。
- 可维护靠机制：数据库约束、关键路径测试、CI、CLAUDE.md、ADR、接口文档自动生成。
